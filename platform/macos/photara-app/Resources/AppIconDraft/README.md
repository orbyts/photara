# Provisional application mark

These are the light and dark vector drafts approved only as working assets on
2026-09-16. Their canvas is transparent; no square tile or white contour is part of
the artwork. Keep both variants together while the shape is refined externally.

They are bundled as resources but are **not** registered as the macOS Dock/Finder
application icon. A later visual approval should prepare native Icon Composer
layers, default/dark/mono variants and small-size checks before changing bundle
icon metadata. No product identity or Auth0 coordinates depend on this artwork.
