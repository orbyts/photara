# PS2 canonical phase subproof (unfrozen)

This disposable, pure-memory candidate links exact original admission bytes, local birth observations, R/C publication accounting, cleanup, ownership release, compact retirement and once-only project credit. It does not implement a production reader, choose permanent names/layouts, qualify a storage provider, or change the existing furnace format.

## What is selected and verified

`proposals/ps2/phases/linked-phases.json` supplies independently generated canonical JSON and 16-byte framed records. Its immutable operation dependency is `operations/linked-operations.json` (SHA-256 `b18f3d5960bff213c35ea12d9f2e32791eb83cc904046d9f47ed21f93ada2421`), whose Core/PS1 semantic oracle remains separately tested. Candidate frames are not native furnace WritePlan frames.

Each physical snapshot includes the unchanged manifest/HEAD/outer-commit bootstrap shape selecting a proposed RootSet, actual StateRoots, semantic inventories, ownership records and locator pages. HEAD authenticates the outer commit; mandatory bootstrap digest, reader capabilities, checked existing scalar types and fixed timestamp are validated. Adjacent distinct commits have exact predecessor commit IDs/hashes and revision +1; the unlink-only phase keeps HEAD unchanged. StateRoot revision 2 has null predecessor; revision 3 binds the actual prior StateRoot hash/revision. Its provenance is a nonedge, and physical relocation preserves the StateRoot bytes.

Active and recovery are independently traversed against typed operation dependencies. Their exact locator memberships include semantic records, StateRoot/inventory and ownership implementation records. Each role's allocation coverage equals its own used allocations, including locator pages: it cannot borrow the other role's claims. Opaque extension-shaped references remain nonedges. The generator's generic reference walk is only a positive oracle; the Rust verifier explicitly dispatches typed edges.

The old snapshot uses source data S and metadata M. Graph publication births A, keeps the same extending M, selects active semantics in A and recovery semantics in S. Release copies recovery content into A and removes both current S ownership edges, retaining S's charge in one exact original-token ticket. Unlink removes S only after authorization; credit requires modeled directory barrier and fresh absence. Both before and after unlink, the supplied destination files are checked against original witnesses, prefix commitments and complete raw framed suffixes, including a deliberately unreachable intermediate record. Credited retry verifies the exact original terminal record, current closure/suffix and absence and returns zero additional credit. Source-independent tests remove all historical source file maps and the separate source bytes before retry.

## Bounded accounting and phase checks

The profile/incarnation-scoped local witnesses are synthetic device/inode observations. The illustrative allocation rule rounds supplied file lengths to 4096 bytes. This is an explicit synthetic measurement profile, not filesystem availability or a portable physical identity contract. Standing control is fixed at 131072 bytes, original Graph reserve 1048576, retirement reserve 524288, cleanup 65536, maximum control frame 16384 and modeled coexistence four. Worst-width control sizing is separate from actual consumed charge. Actual supplied phase bodies must satisfy the original cap, including extensions.

Selected standing control is bound to the original allowance. Tips and sealed charges match this synthetic allocation rule; pending destination growth is covered by the original reserve with cleanup retained. Released/unlinked accounting carries exactly one source ticket with its immutable original charge; credited accounting carries none. R remains immutable; publication atomically models C charged and R−C held. Unlink and cleanup never generate filesystem-space credit.

Birth evidence requires the exact original newborn set, marker before binding, binding before truncation, no-replace promotion and only the exact two-link stage/final pair. The events and barriers are supplied synthetic observations, not demonstrated operating-system operations. Twelve retention categories refuse retirement: the independently selected active/recovery roots and ten additional modeled pin classes.

Reader generations 1 and 2 explicitly dispatch the same admitted codec-v1 canonical bytes without reserialization. Equivalent-value changed bytes and unsupported codecs/readers refuse. This demonstrates a hypothetical compatible reader evolution, not a codec-v2 conversion guarantee or production compatibility promise.

## Deliberate remaining authority gap

OriginalAdmission and phase records are external fixture proofs bound to snapshot HEAD hashes. They are not yet selected by the accounting tree. The external admission currently binds a whole target RootSet: embedding that admission inside the target accounting would create a self-reference. Therefore this is a phase subproof, not the final joined single-authority publication proof.

The joined candidate must bind immutable original bytes to the complete old control base and a target semantic/physical projection excluding the mutable accounting selector, then select original admission, phase and C through HEAD/accounting. It must retain the same typed closure and suffix checks. Current phase inventories and inline sealed accounting are bounded; joining multilevel branch ownership/charge records remains the separate joined candidate's responsibility. No field-equality projection is presented as a substitute for that joined traversal.

Strict scoped Clippy and targeted rustfmt pass.
