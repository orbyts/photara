# Whole-HEAD newborn and original-replay integration checklist

This engineering checklist maps existing disposable evidence into the forthcoming whole-HEAD proposed-coordinate candidate. It introduces no schema names, field spellings, format freeze, production writes or qualification. A positive result must use the final selected typed records and supplied bytes; a projected phase table is not a substitute for the actual HEAD path.

Sources: [fresh generation enrollment](PS2_FRESH_GENERATION_ENROLLMENT.md), [witnessed Graph rollover](PS2_GRAPH_WITNESSED_ROLLOVER.md), [canonical phase subproof](PS2_CANONICAL_PHASE_SUBPROOF.md), [actual birth implementation](../../crates/photara-store/examples/ps2_index_furnace/placement_v3/typed_inventory/fresh_generation.rs), [actual rollover implementation](../../crates/photara-store/examples/ps2_index_furnace/placement_v3/typed_inventory/rollover.rs), and [original Graph dispatch](../../crates/photara-store/examples/ps2_index_furnace/placement_v3/graph_journal/rollover_dispatch.rs).

## Original canonical-byte replay checklist

1. Persist and authenticate exact original canonical bytes and explicit admitted codec identity. Current phase references that immutable identity. A reader upgrade is not permission to recanonicalize the original and substitute a new digest.
2. Explicitly dispatch supported original codecs. Demonstrate a later reader generation consuming the same admitted codec-v1 bytes/hash with the same token, request, reservation, original controls and physical witnesses. Existing phase evidence proves this narrow reader-generation evolution only; it does not already prove a distinct codec-v2 encoding transition.
3. If the whole-HEAD candidate claims a distinct codec transition, provide actual distinct canonical forms and explicit original-version handling under the later reader. Otherwise state the remaining gap. Unsupported original versions and unrecognized required fields must fence before effects and preserve the original evidence.
4. Test equivalent semantic JSON with different bytes, changed codec string, changed original hash, altered prior control reconstruction, and coherent current selector rewrites. None may replace the admitted proof. Optional extension-shaped references remain nonedges; required protocol fields cannot hide in ignored extensions.
5. After source unlink, prove destination prefix/suffix/frame count/witness and exact original charge path from the current supplied files and retained bounded proof. Remove historical source copies/global object stores in a test to rule out hidden fallback. Original target reconstruction must not depend on a deleted source, but actual source absence remains a separate current observation.

## Evidence and scope limits to preserve

The furnace tests are real disposable file operations with controlled returned errors and fresh-handle reopening. They do not qualify arbitrary syscall cuts, all prebinding crashes, abrupt kill/power loss, remount behavior or production allocation bounds. The canonical phase and accounting candidates are pure byte proofs with synthetic local observations/barriers. Matching profile/incarnation strings are an identity precondition, not writable/Saved qualification or copy/rebind permission.

Existing fixture limits—four data/four metadata birth slots, finite finalization tips, numerical frame/control caps and synthetic allocation granularity—are bounded evidence, not a newly approved permanent lifetime or product ceiling. A whole-HEAD proposal must state its exact admitted finite limits and unsupported cases without raising historical caps merely to hide a refusal.

This checklist does not supply the final newborn or codec field specification. The integration lead owns that explicit mapping and the new selected reader; this document is the acceptance inventory against which that mapping can be checked.
